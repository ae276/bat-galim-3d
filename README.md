# מודל תלת-ממדי – שכונת בת גלים, חיפה

מודל אינטראקטיבי של שכונת בת גלים. הוא מציג את המבנים הקיימים, ומעליהם, בחצי שקוף, את כל תוכניות הפיתוח העתידיות (22 תוכניות). המודל כולל גם מוסדות ציבור, קיימים ומתוכננים, ואת שתי הדירות המסומנות: T3·D3 ו-B3·C.

**צפייה:** https://ae276.github.io/bat-galim-3d/

המודל מזהה לבד את המכשיר: במחשב ובטאבלט לרוחב מוצגת תצוגה רחבה עם לוח תוכניות, ובטלפון ובטאבלט לאורך מוצגת תצוגת נייד. אפשר לכפות תצוגה עם הפרמטר `?view=d` (מחשב) או `?view=m` (נייד).

## הטמעה באתר

**אפשרות 1 – סקריפט (מומלץ):**
```html
<div data-bat-galim-3d data-height="700px"></div>
<script src="https://ae276.github.io/bat-galim-3d/embed.js" defer></script>
```

**אפשרות 2 – iframe רגיל:**
```html
<iframe src="https://ae276.github.io/bat-galim-3d/"
        title="מודל תלת-ממדי של שכונת בת גלים"
        style="width:100%;height:min(85vh,760px);border:0"
        loading="lazy" allow="fullscreen" allowfullscreen></iframe>
```
המודל מתאים את עצמו לרוחב המסגרת. במסגרת צרה (פחות מ-760 פיקסלים) הוא עובר לתצוגת הנייד.

## עדכון המודל
הקוד והנתונים נמצאים בתיקייה `src/`. כדי לבנות מחדש:
```bash
cd src
pip install shapely pyproj
python3 gen3.py          # בונה את data.json מכל קבצי המקור
python3 build_unified.py # בונה את index.html בשורש המאגר
```
אחרי שדוחפים את השינויים, GitHub Pages מתעדכן תוך דקה עד שתיים.

| קובץ | תפקיד |
|---|---|
| `index.html` | המודל המלא בקובץ אחד: שתי התצוגות והנתונים |
| `embed.js` | סקריפט ההטמעה |
| `src/template.html`, `src/template_m.html` | תבניות תצוגת המחשב ותצוגת הנייד (three.js) |
| `src/gen2.py`, `src/gen3.py`, `src/inst_part.py` | בניית הנפחים, התוכניות ומוסדות הציבור |
| `src/*.txt` | נתוני מקור מקודדים: מבנים ורחובות, גבולות ותאי שטח, מוסדות |
| `src/data.json` | הנתונים המעובדים שנכנסים לדף |

## מקורות ודיוק
- גבולות התוכניות, תאי השטח וקווי הבניין: מנהל התכנון (XPLAN, מבא"ת).
- קומות וגבהים: טבלה 5 בהוראות התוכניות (רמ"י).
- מוסדות ציבור מתוכננים: נספחי "פרוגרמה לשטחי ציבור".
- מוסדות חינוך קיימים: משרד החינוך (data.gov.il).
- מבנים, רחובות ושאר המוסדות: © תורמי OpenStreetMap.
- חלק מהנפחים משוערים, והם מסומנים כך במודל. אין במודל טופוגרפיה.

המודל אינו מסמך תכנוני רשמי. המידע המחייב נמצא במסמכי התוכניות במבא"ת.
